# 📊 Nathy Invest: Simulador de Investimentos em FIIs

Este projeto foi desenvolvido como parte do desafio prático de Excel da **DIO (Digital Innovation One)**. A ferramenta **Nathy Invest** foi projetada para simular o crescimento de patrimônio em Fundos Imobiliários, focando na visualização do "Efeito Bola de Neve" e no planejamento de longo prazo.

## 🚀 Sobre o Desafio

O objetivo principal é aplicar conhecimentos de Excel para criar uma ferramenta que automatize cálculos financeiros, auxiliando investidores a tomarem decisões baseadas em dados sobre:
* **Acúmulo de Cotas:** Quantas cotas são adquiridas mês a mês com aportes e dividendos.
* **Custo Total vs. Patrimônio:** Acompanhamento do valor investido.
* **Renda Passiva:** Evolução dos rendimentos mensais recebidos.

## 🛠️ Detalhes Técnicos da Planilha

A planilha conta com uma estrutura lógica dividida em:

* **Painel de Projeção (Aba APP):** * **Mês:** Cronograma da simulação.
    * **Custo Total:** Soma dos valores aportados.
    * **Total de Cotas:** Quantidade acumulada de ativos.
    * **Rendimento:** Cálculo do lucro mensal distribuído (Dividendos).
* **Identidade Visual:** Design personalizado em tons de **Azul Profundo** e **Roxo**, cores escolhidas para representar segurança e tecnologia financeira.

## 🧮 Fórmulas e Funcionalidades

Para o desenvolvimento, foram aplicados:
1.  **Cálculos Financeiros:** Projeção de rendimentos baseada em *Dividend Yield*.
2.  **Formatação de Células:** Padronização de moedas ($R\$) e tipos de dados.
3.  **Visualização de Dados:** Organização tabular otimizada para leitura rápida e futura inserção de gráficos de tendência.

## 🎨 Identidade Visual (Nathy Invest)

* **Azul (#1A237E):** Utilizado para cabeçalhos e estrutura principal.
* **Roxo (#7B1FA2):** Utilizado para destacar indicadores de sucesso e metas.
* **Fonte Branca:** Para máximo contraste e acessibilidade.

## 📖 Como utilizar

1. Faça o download do arquivo `Planilha do desafio excel1.xlsx`.
2. Abra no Excel (Online ou Desktop).
3. Na aba **APP**, observe a simulação baseada nos aportes.
4. Utilize os dados para planejar suas metas de independência financeira.
